# 🎨 Color Palette Generator

A simple and interactive web app to generate random color palettes. Built with **HTML, CSS, and JavaScript**, this project allows users to quickly create, view, and copy color codes for design inspiration.

## ✨ Features
- **Generate Palette**: Instantly create a set of 10 random colors.  
- **Interactive Colors**: Each color is displayed with its HEX code.  
- **Copy to Clipboard**: Click on a color or the copy icon to copy its HEX value.  
- **Visual Feedback**: Copy action shows a checkmark confirmation.  
- **Responsive Design**: Works seamlessly across devices.

## 🛠️ Tech Stack
- **HTML5** – Structure  
- **CSS3** – Styling & responsiveness  
- **JavaScript (ES6)** – Logic & interactivity  
- **Font Awesome** – Icons
